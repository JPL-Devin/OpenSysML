SysML v2 · KerML 1.1 · written in Go

Author, check and run systems models from one toolchain.

OpenSysML parses and validates SysML v2 and KerML 1.1, serves an editor over the Language Server Protocol, executes actions, state machines and constraints, and exports models as RDF — with a Python client for the same runtime.

What it does

Parse and validate

A hand-written parser for the full surface syntax, name resolution, and validation split into tiers so a model is checked as strictly as you ask.

Edit anywhere

sysml-lsp speaks the Language Server Protocol — completion, diagnostics, hovers and navigation in VS Code or any LSP client.

Explore in a REPL

An interactive session that keeps your model: instantiate parts, inspect feature values, and step through behavior at a breakpoint.

Execute behavior

Actions, state machines, calculations and constraints really run, with a step budget so a model can never spin forever.

Interoperate

Round-trip models through RDF/Turtle and query them with OSLC query text, so a model is data other tools can read.

Automate from Python

The opensysml package drives the same execution runtime over gRPC, with generated typed classes.

Install

# macOS

go install github.com/Open-MBEE/OpenSysML/cmd/sysml@latest
