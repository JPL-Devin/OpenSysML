# Plan 7 — REPL Frontend (spec §13)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development to execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Implement an interactive REPL (spec §13) as a new command `cmd/sysml-repl` plus a small library package `internal/repl`, layered as a thin frontend over the existing `model.Workspace`. Each submission is parsed as top-level namespace member(s), accumulated into one implicit in-memory `<repl>` document that persists across inputs, eagerly analyzed, and echoed as either a resolved summary (kind + qualified name per declared member) or rendered diagnostics with caret spans. Supports readline history/line-editing, `...` continuation prompting for unterminated input, redefine-replaces semantics, and v1 meta commands `%help`/`%list`/`%clear`/`%load <file>`.

**Architecture:** `internal/repl` owns a `Session` that wraps a single `*model.Workspace`. The session holds an **ordered list of accepted submission source snippets** (each tagged with the set of top-level names it declares). The implicit `<repl>` document is the newline-join of all surviving snippets; on each accepted submission the session drops any earlier snippet that declared a name the new submission redeclares (redefine-replaces), appends the new snippet, then calls `ws.Open("<repl>", joined, version++)` — reusing the entire existing parse+index+diagnostics pipeline unchanged. Analysis is eager: immediately after `Open`, the session pulls `ws.Diagnostics("<repl>")` and the parsed `ws.Document("<repl>")` to build output. `cmd/sysml-repl` is a thin driver: a `chzyer/readline` loop that reads (with continuation buffering), routes `%`-prefixed lines to meta commands, feeds everything else to `Session.Submit`, and prints the returned rendering. Continuation is detected by lexing the buffered input and tracking unmatched `{ ( [` depth, augmented by a trailing-`expected` parse-diagnostic heuristic; a blank line force-flushes.

**Tech Stack:** Go 1.25 stdlib + `github.com/chzyer/readline` (latest, pure-Go, history + line editing) and existing internal pkgs (`model`, `ast`, `parser`, `lexer`, `source`, `symbols`, `passes`). No changes to core analysis packages are expected; any needed accessor is added narrowly (see Constraints).

## Scope

**In scope (spec §13), v1:**

- **Loop** — `chzyer/readline` with persistent history file and line editing; primary prompt `> `, continuation prompt `... `.
- **Statement-by-statement** — each submission parsed as top-level `RootNamespace` members and folded into the implicit `<repl>` namespace.
- **Session state** — accumulated declarations persist in the in-memory `<repl>` document; later inputs resolve against earlier ones + stdlib + imports. Redefining the same top-level name replaces the prior declaration.
- **Continuation detection** — unmatched brace/paren/bracket depth (via the lexer) plus a parser "expected more" heuristic → secondary prompt; blank line force-flushes the buffer.
- **Output** — success → one summary line per declared member (`kind qualified::name`); errors → diagnostics rendered with source line + caret (`^~~~`) spans against the submission.
- **Eager resolution** — analysis runs on every submission (unlike the lazy LSP path), surfacing unresolved-reference diagnostics immediately.
- **Meta commands** — `%help`, `%list` (dump current session declarations), `%clear` (reset session), `%load <file>` (read a file and submit its contents into the session).
- **Imports & stdlib** — `import` works as in source files; stdlib lazy-loads on first reference through the existing workspace machinery.

**Deferred (roadmap, NOT this plan):** visualization, publish/export, multi-line editor mode, tab-completion inside the REPL (LSP completion exists separately), non-interactive script runner beyond `%load`, transactional undo of a submission.

**Constraints discovered:**

- **No parser "incomplete" flag.** `parser.Parser` reports problems only as `Diagnostics` (`p.error`/`p.expect` push messages like `"expected '}'"`); there is no dedicated end-of-input/incomplete signal (verified `internal/core/parser/parser.go`, `namespace.go`). Continuation therefore relies primarily on **lexer brace-depth** (deterministic) with the trailing-`expected`-diagnostic as a secondary hint.
- **`model.Document.sf` is private** (document.go:20) — for caret rendering the session reconstructs line/column from the submission's own bytes rather than from the doc, OR uses `source.New(name, content)` to map offsets → line/col (same technique Plan 6 used). Confirm the exact `source` API in Task 6.
- **Redefine-replaces is a REPL-frontend concern**, not a core feature: core `symbols.Build`/index would emit duplicate-name diagnostics if two decls of the same name coexisted, so the session must physically drop superseded snippets before re-`Open`. Declared names are read from the just-parsed submission AST (`Package`/`Namespace`/`Alias` → `Ident.Name`; unnamed/`Import`/`Comment`/`Dependency`/`FilterMember` declare nothing replaceable).
- **`<repl>` document name** is used verbatim as the workspace key and as the pseudo-filename passed to `source.New`; it never touches disk.
- Reuses existing `Workspace` API only: `Open(name, content, version)`, `Diagnostics(name)`, `Document(name)`, `Remove(name)` (for `%clear`). No new `Workspace` method anticipated.

## Session Accumulation Model

The session is a list of `snippet{src, names}` in acceptance order. `<repl>` document content = `strings.Join(snippet.src for all snippets, "\n")`.

On `Submit(src)`:

1. Tentatively parse `src` alone (via `source.New("<repl-input>", src)` + `parser.New(...).ParseFile()`) to (a) check for continuation and (b) compute `declaredNames`.
2. Compute the new snippet's declared names. Remove from the ordered list any existing snippet whose `names` intersect the new names (redefine-replaces). Append the new snippet.
3. Rebuild joined content; `ws.Open("<repl>", joined, version++)`.
4. Pull `ws.Diagnostics("<repl>")` + `ws.Document("<repl>")`; build `Result`.

`%clear` → `ws.Remove("<repl>")`, empty the snippet list, reset version. `%load <file>` → read file bytes, `Submit(string(bytes))` (multi-member input is fine; the whole file is one snippet).

**Edge:** if a submission itself fails to parse cleanly (parse diagnostics), it is still appended (so the user sees the error against accumulated context) — matching pilot behavior where erroneous input is reported, not silently dropped. (Confirm/adjust in Task 4; alternative: reject on parse error and do not accumulate. Decision recorded there.)

## Continuation Detection

`needsContinuation(buf)` lexes `buf` with the existing `lexer` and counts `LBrace/RBrace`, `LParen/RParen`, `LBracket/RBracket`. If any counter is positive (more opens than closes) → continuation. A blank line typed at the `...` prompt force-flushes regardless (submit what we have; let the parser report the error). Secondary heuristic: if depth is balanced but the final non-trivia token leaves an obviously-open declaration (e.g. trailing `::` or `=`), continue — kept minimal; brace-depth is the primary, reliable signal. Exact lexer token-kind names verified in Task 3.

```go
package repl

import "github.com/Open-MBEE/Systemica/internal/core/ast"

// declaredNames returns the replaceable top-level names introduced by a parsed
// submission, in source order. Only Package/Namespace/Alias declarations carry a
// name that the redefine-replaces logic acts on; imports/comments/etc. declare
// nothing replaceable.
func declaredNames(root *ast.RootNamespace) []string {
	if root == nil {
		return nil
	}
	var out []string
	for _, m := range root.Members {
		node := m
		if mem, ok := m.(*ast.Membership); ok {
			node = mem.Member
		}
		var name string
		switch d := node.(type) {
		case *ast.Package:
			name = d.Ident.Name
		case *ast.Namespace:
			name = d.Ident.Name
		case *ast.Alias:
			name = d.Ident.Name
		}
		if name != "" {
			out = append(out, name)
		}
	}
	return out
}
```

```go
import (
	"strings"

	"github.com/Open-MBEE/Systemica/internal/core/parser"
	"github.com/Open-MBEE/Systemica/internal/core/source"
)

// accept parses src to compute its declared names, drops any earlier snippet
// whose names intersect, appends the new snippet, and returns the joined
// <repl> content. It does NOT touch the workspace (Task 4 does).
func (s *Session) accept(src string) string {
	root := parser.New(source.New(docName, []byte(src))).ParseFile()
	names := declaredNames(root)
	if len(names) > 0 {
		set := make(map[string]bool, len(names))
		for _, n := range names {
			set[n] = true
		}
		kept := s.snippets[:0]
		for _, sn := range s.snippets {
			if !intersects(sn.names, set) {
				kept = append(kept, sn)
			}
		}
		s.snippets = kept
	}
	s.snippets = append(s.snippets, snippet{src: src, names: names})
	return s.joined()
}

func (s *Session) joined() string {
	parts := make([]string, len(s.snippets))
	for i, sn := range s.snippets {
		parts[i] = sn.src
	}
	return strings.Join(parts, "\n")
}

func intersects(names []string, set map[string]bool) bool {
	for _, n := range names {
		if set[n] {
			return true
		}
	}
	return false
}
```

Lex the buffer and track group depth. Token kinds confirmed in `internal/core/lexer/token.go`: `LBrace`/`RBrace`, `LParen`/`RParen`, `LBracket`/`RBracket`, `EOF`. Depth going negative (stray close) is clamped so it does not falsely trigger continuation. Continuation = any group still open at EOF.

`internal/repl/continuation.go`:
```go
package repl

import (
	"github.com/Open-MBEE/Systemica/internal/core/lexer"
	"github.com/Open-MBEE/Systemica/internal/core/source"
)

// needsContinuation reports whether buf has an unterminated brace/paren/bracket
// group and should prompt for more input. Brace depth is the primary, reliable
// signal; a blank line at the continuation prompt force-flushes at the call site
// (Task 8), so this function never needs to special-case emptiness beyond
// returning false for balanced/empty input.
func needsContinuation(buf string) bool {
	lx := lexer.New(source.New("<repl-input>", []byte(buf)))
	var brace, paren, bracket int
	for {
		tok := lx.Next()
		switch tok.Kind {
		case lexer.LBrace:
			brace++
		case lexer.RBrace:
			if brace > 0 {
				brace--
			}
		case lexer.LParen:
			paren++
		case lexer.RParen:
			if paren > 0 {
				paren--
			}
		case lexer.LBracket:
			bracket++
		case lexer.RBracket:
			if bracket > 0 {
				bracket--
			}
		case lexer.EOF:
			return brace > 0 || paren > 0 || bracket > 0
		}
	}
}
```

```go
// Submit accumulates src into the <repl> document, reindexes and eagerly
// analyzes the whole buffer, and returns a Result. Submissions are always
// accumulated (even with parse errors) so diagnostics are reported against the
// live session context; a later redeclaration of the same name replaces the
// prior snippet (see accept).
func (s *Session) Submit(src string) Result {
	declared := declaredNames(parser.New(source.New(docName, []byte(src))).ParseFile())
	joined := s.accept(src)
	s.version++
	s.ws.Open(docName, []byte(joined), s.version)
	diags := s.ws.Diagnostics(docName)
	var members []ast.Node
	if doc := s.ws.Document(docName); doc != nil && doc.AST != nil {
		members = doc.AST.Members
	}
	return Result{
		Members:     members,
		Declared:    declared,
		Diagnostics: diags,
		Source:      joined,
	}
}
```

- [ ] **Step 3: Implement summary rendering in `render.go`**

`renderSummary` walks `Result.Members`, unwrapping `*ast.Membership`. `renderMember` maps each node to `"<kind> <name>"`. For `Import` there is no name → render the imported qualified name. Use `ast.QualifiedName.Parts` (each `NameSegment.Text`) joined by `::`.

```go
import "strings"

// renderSummary returns one summary line per top-level member: "<kind> <name>".
func renderSummary(members []ast.Node) []string {
	out := make([]string, 0, len(members))
	for _, m := range members {
		if line := renderMember(m); line != "" {
			out = append(out, line)
		}
	}
	return out
}

// renderMember maps a top-level member (possibly wrapped in a Membership) to a
// "<kind> <name>" summary, or "" for members that carry no useful summary.
func renderMember(m ast.Node) string {
	node := m
	if mem, ok := m.(*ast.Membership); ok {
		node = mem.Member
	}
	switch d := node.(type) {
	case *ast.Package:
		return "package " + nameOrAnon(d.Ident)
	case *ast.Namespace:
		return "namespace " + nameOrAnon(d.Ident)
	case *ast.Alias:
		return "alias " + nameOrAnon(d.Ident)
	case *ast.Import:
		return "import " + qnString(d.Imported)
	case *ast.Dependency:
		return "dependency " + nameOrAnon(d.Ident)
	case *ast.Comment:
		return "comment"
	default:
		return ""
	}
}

func nameOrAnon(id ast.Identification) string {
	if id.Name != "" {
		return id.Name
	}
	if id.ShortName != "" {
		return "<" + id.ShortName + ">"
	}
	return "<anonymous>"
}

func qnString(qn *ast.QualifiedName) string {
	if qn == nil {
		return "<?>"
	}
	parts := make([]string, len(qn.Parts))
	for i, p := range qn.Parts {
		parts[i] = p.Text
	}
	return strings.Join(parts, "::")
}
```

Map each diagnostic's byte `Span` to line/col with `source.New(docName, []byte(src)).Lines().PosAt(offset)` (confirmed `source` API: `New`, `(*SourceFile).Lines() *LineIndex`, `(*LineIndex).PosAt(offset int) source.Pos` with 1-based `Line`/`Col`). Extract the offending source line directly from `src` (split on `\n`; `Pos.Line-1` index). Build a caret line: `Col-1` spaces then `^` followed by `~` for `Span.Len-1` (min width 1), clamped to the line length.

```go
import (
	"fmt"
	"strings"

	"github.com/Open-MBEE/Systemica/internal/core/source"
)

// renderDiagnostics formats each diagnostic as a two-line block:
//   <line>:<col>: <severity>: <message>
//       <source line>
//       <caret span>
func renderDiagnostics(diags []passes.Diagnostic, src string) []string {
	if len(diags) == 0 {
		return nil
	}
	sf := source.New(docName, []byte(src))
	lines := strings.Split(src, "\n")
	var out []string
	for _, d := range diags {
		p := sf.Lines().PosAt(d.Span.Offset)
		out = append(out, fmt.Sprintf("%d:%d: %s: %s", p.Line, p.Col, d.Severity.String(), d.Message))
		if p.Line-1 >= 0 && p.Line-1 < len(lines) {
			srcLine := lines[p.Line-1]
			out = append(out, srcLine)
			out = append(out, caretLine(p.Col, d.Span.Len, len(srcLine)))
		}
	}
	return out
}

// caretLine builds "   ^~~~" with (col-1) leading spaces and a caret span of
// width max(1, spanLen), clamped so it never runs past the source line.
func caretLine(col, spanLen, lineLen int) string {
	if col < 1 {
		col = 1
	}
	lead := col - 1
	width := spanLen
	if width < 1 {
		width = 1
	}
	if lead+width > lineLen {
		width = lineLen - lead
		if width < 1 {
			width = 1
		}
	}
	var b strings.Builder
	b.WriteString(strings.Repeat(" ", lead))
	b.WriteByte('^')
	if width > 1 {
		b.WriteString(strings.Repeat("~", width-1))
	}
	return b.String()
}
```
**Note:** byte-column carets assume ASCII/monospace alignment; multi-byte runes before the caret will misalign by display width. Acceptable for v1 (LSP owns UTF-16; REPL is a terminal aid). Record this limitation in a code comment.

- [ ] **Step 3: Implement `meta.go`**

`runMeta` returns `(out []string, quit bool, err error)`. Unknown commands return a helpful error line (not a Go error). `%load` reads the file and calls `Submit`, folding the whole file in as one snippet; its returned `Result` is rendered via Tasks 5/6 helpers so the user sees the summary/diagnostics.

```go
package repl

import (
	"fmt"
	"os"
	"strings"
)

// isMeta reports whether a trimmed input line is a meta command.
func isMeta(line string) bool {
	return strings.HasPrefix(strings.TrimSpace(line), "%")
}

var helpText = []string{
	"%help          show this help",
	"%list          list current session declarations",
	"%clear         reset the session",
	"%load <file>   read a file and submit its contents",
}

// runMeta executes a meta command line. Returns lines to print, whether to quit,
// and an error only for unrecoverable I/O (unknown commands print guidance).
func (s *Session) runMeta(line string) (out []string, quit bool, err error) {
	fields := strings.Fields(strings.TrimSpace(line))
	if len(fields) == 0 {
		return nil, false, nil
	}
	switch fields[0] {
	case "%help":
		return helpText, false, nil
	case "%list":
		decls := s.List()
		if len(decls) == 0 {
			return []string{"(empty session)"}, false, nil
		}
		return decls, false, nil
	case "%clear":
		s.Clear()
		return []string{"session cleared"}, false, nil
	case "%load":
		if len(fields) < 2 {
			return []string{"usage: %load <file>"}, false, nil
		}
		data, rerr := os.ReadFile(fields[1])
		if rerr != nil {
			return nil, false, fmt.Errorf("load %s: %w", fields[1], rerr)
		}
		r := s.Submit(string(data))
		return renderResult(r), false, nil
	default:
		return []string{fmt.Sprintf("unknown command %q (try %%help)", fields[0])}, false, nil
	}
}
```

```go
package repl

import (
	"bufio"
	"errors"
	"io"
	"strings"
)

const (
	primaryPrompt = "> "
	contPrompt    = "... "
)

// Loop runs the read/eval/print cycle until the reader returns io.EOF (Ctrl-D).
func Loop(r LineReader, out io.Writer, s *Session) error {
	w := bufio.NewWriter(out)
	defer w.Flush()
	var buf strings.Builder
	prompt := primaryPrompt
	for {
		line, err := r.ReadLine(prompt)
		if errors.Is(err, io.EOF) {
			return nil
		}
		if err != nil {
			return err
		}
		// Meta commands only at the primary prompt with an empty buffer.
		if buf.Len() == 0 && isMeta(line) {
			metaOut, quit, merr := s.runMeta(line)
			printLines(w, metaOut)
			w.Flush()
			if merr != nil {
				printLines(w, []string{"error: " + merr.Error()})
				w.Flush()
			}
			if quit {
				return nil
			}
			continue
		}
		// Blank line at continuation prompt force-flushes.
		if buf.Len() > 0 && strings.TrimSpace(line) == "" {
			submit(w, s, buf.String())
			buf.Reset()
			prompt = primaryPrompt
			w.Flush()
			continue
		}
		if buf.Len() > 0 {
			buf.WriteByte('\n')
		}
		buf.WriteString(line)
		if needsContinuation(buf.String()) {
			prompt = contPrompt
			continue
		}
		if strings.TrimSpace(buf.String()) != "" {
			submit(w, s, buf.String())
		}
		buf.Reset()
		prompt = primaryPrompt
		w.Flush()
	}
}

func submit(w io.Writer, s *Session, src string) {
	printLines(w, renderResult(s.Submit(src)))
}

func printLines(w io.Writer, lines []string) {
	for _, l := range lines {
		io.WriteString(w, l+"\n")
	}
}
```

```go
package main

import (
	"fmt"
	"io"
	"os"
	"path/filepath"

	"github.com/chzyer/readline"

	"github.com/Open-MBEE/Systemica/internal/repl"
)

type rlReader struct{ rl *readline.Instance }

func (r *rlReader) ReadLine(prompt string) (string, error) {
	r.rl.SetPrompt(prompt)
	line, err := r.rl.Readline()
	if err == readline.ErrInterrupt { // Ctrl-C clears the current line, not EOF
		return "", nil
	}
	if err == io.EOF {
		return "", io.EOF
	}
	return line, err
}

func main() {
	if err := run(); err != nil {
		fmt.Fprintln(os.Stderr, "sysml-repl:", err)
		os.Exit(1)
	}
}

func run() error {
	histPath := filepath.Join(os.TempDir(), "sysml-repl.history")
	rl, err := readline.NewEx(&readline.Config{
		Prompt:          "> ",
		HistoryFile:     histPath,
		InterruptPrompt: "^C",
		EOFPrompt:       "bye",
	})
	if err != nil {
		return err
	}
	defer rl.Close()
	fmt.Println("SysML v2 REPL — %help for commands, Ctrl-D to exit")
	return repl.Loop(&rlReader{rl: rl}, os.Stdout, repl.NewSession())
}
```
