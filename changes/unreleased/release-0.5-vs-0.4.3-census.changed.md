- **Release performance comparison against 0.4.3.** `docs/project/performance-release-0.5-vs-0.4.3.md` measures `main` against the `v0.4.3` tag — every Go benchmark under `benchstat`, whole-binary `sysml -validate` scaling, process start and the `examples/` models — and records each regression with its cause, the change responsible, its size and whether it is fixed here, explained, or open with a proposed fix. Loading is 14–19% slower than 0.4.3 after the fixes below (new validation passes), starting a state machine with no exhibitor scans the model once per start, and a gRPC `VerifyConstraint` request rebuilds its runtime per call; the last two are open with proposed fixes.
