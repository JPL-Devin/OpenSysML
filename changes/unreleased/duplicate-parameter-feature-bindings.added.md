- **An invocation that binds one parameter twice, and a constructor expression that binds one feature twice, are reported at the type tier.** `F(x = 1, x = 2)` is `F binds parameter "x" twice` and `new C(x = 1, x = 2)` is `C binds feature "x" twice`, judged by the parameter or feature the name resolves to rather than by its spelling: a short name, an alias, a qualified name or a redefining name of the same parameter or feature counts as the same binding, in KerML function calls, `calc` usages, `action a = A(…)`, `perform action a = A(…)` and `send new Sig(…)` alike (KerML 1.1 §8.3.4.8 `validateInvocationExpressionNoDuplicateParameterRedefinition`, `validateConstructorExpressionNoDuplicateFeatureRedefinition`). The named arguments of a constructor expression are now kept by the parser, so they survive the AST dump, the binary codec, reference collection and the RDF export.
