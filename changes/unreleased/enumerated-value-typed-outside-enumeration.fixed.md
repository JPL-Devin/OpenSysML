- **An enumerated value typed outside its enumeration is now an error, and one typed by a general of it no longer is.** A value written on an enumerated value types it (`enum def E :> Real { b = 3; }` types `b` by Integer), and so does a declared type; either counts as a second type beside the owning enumeration unless the enumeration specializes it, exactly as the reference implementation's `validateEnumerationUsageType` decides. `enum def E :> Real { a : Real; }` was wrongly rejected before.
